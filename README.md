# Studio Nook — Responsive Business Website (Demo)

A polished, **fictional** interior-design studio website built with HTML, CSS and JavaScript. All projects and branding are concept examples, not client work.

## Features
- Responsive navigation and mobile menu
- Service sections with direct enquiry actions
- Filterable concept portfolio (All / Residential / Commercial)
- Validated enquiry form: launches your email app with prefilled enquiry, or copies the enquiry to clipboard
- Semantic page sections, accessible labels, basic metadata, mobile layout

## Run locally
Open `index.html` in a browser. No installation or build step required.

## Deploy on GitHub Pages
1. Create a **public** repository named `portfolio-business-website`.
2. Upload this `index.html` and `README.md` in the repository root.
3. Go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. The URL should follow `https://YOUR_USERNAME.github.io/portfolio-business-website/` after GitHub Pages finishes deploying.

## Important
This project is a static portfolio concept. The enquiry form is a `mailto:`/clipboard demo, **not a server-submitted form**. Replace the example email and add a real form backend and privacy safeguards before using with a live client.
